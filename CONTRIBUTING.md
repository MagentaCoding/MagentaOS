# MagentaOS Contributing Guidelines

These guidelines describe how contributions to MagentaOS are handled. Currently, MagentaOS is in an early planning and preparation phase, and there is no active public development yet.

Contributions are therefore **not required**, but they are generally possible if they are relevant, meaningful, and aligned with the goals of MagentaOS.

---

## 1. General Contribution Status

MagentaOS is currently developed primarily by the project owner and the MagentaOS Team. There is **no official contributor program** at this stage, and there is no obligation to accept external contributions.

Pull Requests may still be submitted if they:

- provide a clear technical benefit
- align with the concept and objectives of MagentaOS
- do not violate existing rules, licenses, or guidelines

There is **no guarantee** that submitted Pull Requests will be reviewed, accepted, or responded to.

## 2. Pull Requests

When submitting a Pull Request, the following rules apply:

- Contributions must be factual, technical, and project-related
- Code or content must be clearly documented
- Pull Requests must not contain political, ideological, or activist content
- Pull Requests are subject to the MagentaOS Code of Conduct

By submitting a Pull Request, you confirm that you hold the rights to your contribution and are authorized to provide it to MagentaOS.

## 3. Rights to Contributions

To anything regarding the copyright claims of the content of your contribution see the [MagentaOS License](./LICENSE.md#copyright-of-user-generated-content-functions-and-security-fixes)

## 4. Communication

All discussions regarding contributions must be factual and respectful. Violations of the MagentaOS Code of Conduct may result in immediate rejection of a submission.

## 5. Changes to These Guidelines

These Contributing Guidelines may be updated or expanded at any time, especially as MagentaOS enters active development.
